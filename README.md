# Xbox UWP Drive Permission Tool

This version keeps the original permission functionality and only includes a few cleanup and usability improvements.

## Changes Made

- Cleaned up warnings left in the original source.
- Only compatible **NTFS** drives are shown.
- FAT32, exFAT, and unsupported drives are hidden.
- The permission button is disabled when no compatible NTFS drive is detected.
- Added/kept a Refresh button to rescan connected drives.
- Simplified the drive list so it only shows useful information such as drive letter, name, NTFS format, and size.

## Build

Open the solution in Visual Studio and build the project normally
