# Xbox UWP Drive Permission tool
<img width="402" height="232" alt="image" src="https://github.com/user-attachments/assets/7a5aedb3-352b-4d8a-94b5-5c0242f7a2be" />

- This Application will ONLY add ALL APPLICATION PACKAGES to your external drive and does not delete any data.
- If a External Drive is not properly formatted to NTFS already it will give you an error to please format to NTFS first
- WILL ONLY show External drives connected (USB Sticks or HDD)
- Select Auto Apply Permissions and done!
